shields.ioで使用するためのエンドポイントです。
スタイルの上書きなどは[shields.io](https://shields.io/badges/endpoint-badge)のドキュメントを参照してください。

## GET `/badges/users/:username/rating`

CHUNITHM-NETから取得した公式RATINGを、shields.ioのバッジとして取得します。

**パスパラメータ:**

| パラメータ | 型 | 説明 |
| ---------- | -- | ---- |
| `username` | string | ユーザー名 |

<BadgeMaker
  label="CHUNITHM RATING"
  endpoint="/badges/users/:username/rating"
  defaultParams={{
    username: "sevenc7c"
  }}
  linkTo="/users/:username"
/>
