ChuniSupportを利用するときの共通ルールです。アカウントを登録する場合は、この規約への同意が必要です。

3. 本サービス上の個別の説明、注意事項、APIドキュメントその他のルール（以下「個別ルール」といいます。）も、本規約の一部を構成します。

## 4. プレイデータと公開設定

:::note[かんたんに言うと]
自分のプレイデータだけを登録してください。プロフィールは最初は公開です。非公開にするとユーザーごとの記録は見えなくなりますが、記録は引き続き全体統計やデータ分析に使われ、特徴的なスコアなどから本人が推測される場合があります。
:::

1. 利用者は、自分が正当に利用できるプレイデータのみを本サービスへ登録できます。他人のアカウントやプレイデータを、本人の許可なく登録してはなりません。
2. 利用者は、ブックマークレットその他の方法でプレイデータを登録するとき、利用するウェブサイトや外部サービスの利用条件を自ら確認し、これを遵守するものとします。
3. プロフィールの初期設定は「公開」です。公開中は、ユーザー名、プレイヤー名、プレイ記録、レーティング、統計その他プロフィールに表示される情報を第三者が閲覧できます。
4. 利用者は、設定画面からプロフィールを「非公開」に変更できます。非公開にすると、ユーザー名に紐づくプロフィールやプレイ記録は、本人、承認済みフレンドその他本サービスが認めた範囲を除き、第三者から閲覧できなくなります。
5. 公開設定にかかわらず、登録されたプレイデータは、楽曲別のスコア分布、平均値、最高値その他の統計の作成および公開ならびに統計的分析、傾向分析、機械学習・AIを含む手法によるモデルまたはアルゴリズムの開発、学習、評価および改善に利用されます。統計の作成および分析に際しては、ユーザー名、プレイヤー名、Firebase UIDその他利用者を直接識別する情報を削除または分離するよう努めますが、特徴的な記録や他の情報との組合せから、記録した利用者またはその利用事実が推測される可能性を完全に排除できるものではありません。
6. 利用者が退会した場合、その利用者の元のプレイデータを削除し、以後、新たな統計および分析の対象として利用しません。ただし、退会前に作成された統計的な集計結果、分析結果ならびに学習済みのモデルおよびアルゴリズムのうち、元のプレイデータを復元できず、かつ、利用者を直接識別する情報を含まないものについては、削除、再集計または再学習を行わない場合があります。
7. 公開設定の変更や退会より前に第三者が保存した情報、検索エンジンのキャッシュその他運営者が管理できない情報については、運営者が削除できない場合があります。

:::

2. APIトークンは、発行を受けた利用者本人が管理するものとします。利用者は、APIトークンを第三者へ公開または共有してはなりません。
3. APIを利用した次の行為を禁止します。
   - 有料機能、有料サービスまたは有料商品の提供
   - 広告を掲載したウェブサイト、アプリその他の媒体での利用
   - APIから取得したデータの販売、貸与または有償での再配布
   - その他、これらに準じ、APIの利用またはAPIから取得したデータの対価として収益を得る利用
   - APIから取得したユーザーデータを、取得時に本人へ明示した目的または当該API機能の提供に合理的に必要な範囲を超えて利用する行為
   - 統計、集計その他個人を直接識別することを予定していない情報から利用者を特定もしくは推測し、または他の情報と組み合わせて利用者の行動、能力、嗜好その他のプロフィールを作成する行為
   - 公開設定、認証、アクセス権限その他の制限を回避し、またはこれらの制限を実質的に損なう形でユーザーデータを取得、保存もしくは再公開する行為
4. 利用者は、APIドキュメントに記載されたレート制限、認証、公開範囲その他の技術的制限に従うものとし、これらの制限を回避してはなりません。利用者が公開設定を変更し、または退会する前に第三者がAPIから取得して保存した情報について、運営者は、当該第三者による削除、更新または利用停止を保証しません。
5. 運営者は、安全性、負荷、機能変更その他運営上の必要に応じて、APIの仕様、利用上限または提供範囲を変更することがあります。
