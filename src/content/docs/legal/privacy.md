ChuniSupport運営者（以下「運営者」といいます。）は、ChuniSupport（以下「本サービス」といいます。）における利用者に関する情報を、本プライバシーポリシーに従って取り扱います。

## 1. 適用範囲と運営主体

:::note[かんたんに言うと]
このポリシーは、ChuniSupportのウェブサイト、API、ブックマークレットなどで取り扱う利用者情報について説明するものです。ChuniSupportは個人が運営しています。
:::

1. 本ポリシーは、本サービスのウェブサイト、API、ブックマークレットその他運営者が提供する機能に適用されます。
2. 本サービスは、運営者が個人で開発・運営しています。
3. 外部サービスが独自に取得する情報には、当該外部サービスのプライバシーポリシーが適用されます。

## 2. 取り扱う情報

:::note[かんたんに言うと]
ログイン情報、ChuniSupportのユーザー名、プレイ記録、公開設定、フレンド、APIトークンの管理情報、アクセスログなどを取り扱います。Googleアカウントのパスワードは保存しません。
:::

本サービスでは、次の情報を取り扱います。

1. **認証に関する情報**
   - Firebase Authenticationの利用者識別子（Firebase UID）
   - メールアドレス、表示名、プロフィール画像、Google側の利用者識別子その他GoogleログインによりFirebase Authenticationへ提供される情報
   - 認証日時、アカウントの状態その他Firebase Authentication上に記録される情報
2. **本サービスのアカウント情報**
   - ユーザー名、登録日時、更新日時、公開・非公開設定
   - アカウント種別、権限、不正利用の確認に必要な状態情報
3. **プレイデータと利用者が登録する情報**
   - プレイヤー名、レーティング、オーバーパワー、スコア、ランク、称号、コース記録その他のプレイ記録
   - スコア履歴、目標、お気に入り楽曲、未解禁楽曲、保存した検索条件その他利用者が登録する情報
4. **交流機能に関する情報**
   - フレンド関係、フレンド申請およびその状態
5. **APIに関する情報**
   - APIトークンのハッシュ、識別用の一部文字列、名称、発行日時、最終利用日時その他の管理情報
6. **一時登録データと通信・運用記録**
   - 利用登録前に一時的に送信されるプレイデータおよびIPアドレス
   - IPアドレス、アクセス日時、リクエスト情報、ブラウザや端末に関する情報、エラー情報その他のアクセスログ
7. **端末内に保存される情報**
   - ログイン状態、テーマ、表示設定、検索条件、楽曲情報やプレイ記録のキャッシュその他Cookie、ローカルストレージまたはIndexedDB等に保存される情報
8. **利用状況に関する情報**
   - 閲覧したページ、利用した機能、端末やブラウザに関する情報その他Firebase Analytics等により取得される利用状況
9. **問い合わせに関する情報**
   - 返信先メールアドレス、ユーザー名、問い合わせ内容、対応履歴その他利用者が問い合わせフォームへ入力する情報

本サービスのデータベースでは、Googleアカウントのパスワードを保存しません。APIトークンは、そのままの文字列ではなくハッシュ化して保存します。

## 3. 情報の取得方法

:::note[かんたんに言うと]
利用者が入力・登録した情報、Googleログインから提供される情報、アクセス時に自動的に記録される情報を取得します。ブックマークレットは、利用者自身の操作でプレイデータを送信します。
:::

運営者は、主に次の方法で情報を取得します。

1. 利用者が、本サービスの画面、APIまたは問い合わせフォームへ入力もしくは送信する方法
2. 利用者がブックマークレットを実行し、CHUNITHM-NET上に表示された自己のプレイデータを本サービスへ送信する方法
3. GoogleログインおよびFirebase Authenticationを通じて取得する方法
4. 利用者が本サービスへアクセスしたときに、サーバー、セキュリティ機能またはアクセス解析機能が自動的に記録する方法
5. 利用者の端末内へCookie、ローカルストレージまたはIndexedDB等を保存し、またはこれらを読み出す方法

## 4. 利用目的

:::note[かんたんに言うと]
取得した情報は、ログイン、プレイ記録や統計の表示、データ分析、機械学習・AIを含むモデル等の開発・改善、フレンド・API機能、不正利用対策、サービス改善、問い合わせ対応などに使います。
:::

運営者は、取り扱う情報を次の目的で利用します。

1. 本人認証、利用登録、ログインおよびアカウント管理のため
2. プレイ記録、レーティング、目標、検索、フレンドその他本サービスの機能を提供するため
3. 公開設定に応じてプロフィールおよびプレイ記録を表示するため
4. 楽曲別のスコア分布、平均値、最高値その他の統計を作成し、表示するため
5. プレイデータを用いた統計的分析、傾向分析その他のデータ分析ならびに機械学習・AIを含む手法によるモデルまたはアルゴリズムの開発、学習、評価および改善のため
6. APIトークンの発行、認証、利用状況の管理およびAPIの提供のため
7. 不正利用、規約違反、過度なアクセスその他本サービスの安全を害する行為を検知、防止および調査するため
8. 障害対応、保守、品質向上、利用状況の把握および機能改善のため
9. 問い合わせ、情報の確認・訂正・削除等の申出および紛争へ対応するため
10. [利用規約](/legal/terms/)を執行し、利用者または第三者の権利利益を保護するため
11. 法令上の義務を履行するため

## 5. 公開される情報、統計および分析

:::note[かんたんに言うと]
プロフィールは最初は公開です。非公開にするとユーザーごとの情報は見えなくなりますが、プレイ記録は引き続き統計や分析に使われます。分析時には名前などを削除・分離するよう努めますが、特徴的なスコアなどから本人が推測される可能性を完全にはなくせません。
:::

1. プロフィールの初期設定は「公開」です。公開中は、ユーザー名、プレイヤー名、プレイ記録、レーティング、統計その他プロフィールに表示される情報を第三者が閲覧できます。
2. GoogleログインによりFirebase Authenticationへ提供されるメールアドレス、表示名、プロフィール画像その他のGoogleアカウント情報は、他の利用者へ公開せず、公開プロフィール、公開APIおよび公開統計にも表示しません。
3. 利用者は、設定画面からプロフィールを「非公開」に変更できます。非公開にすると、ユーザー名に紐づくプロフィールやプレイ記録は、本人、承認済みフレンドその他本サービスが認めた範囲を除き、第三者から閲覧できなくなります。
4. 公開設定にかかわらず、登録されたプレイデータは、楽曲別のスコア分布、平均値、最高値その他の統計の作成および公開ならびに前条第5号に定める分析に利用されます。
5. 統計の作成および分析に際しては、ユーザー名、プレイヤー名、Firebase UIDその他利用者を直接識別する情報を、分析対象のデータから削除または分離するよう努めます。ただし、最高値その他の特徴的な記録や、利用者自身または第三者が公開した情報との組合せから、記録した利用者またはその利用事実が推測される可能性を完全に排除できるものではありません。
6. 公開する統計については、対象人数や記録の特徴などを考慮し、個人が推測される可能性を低減するため、必要に応じて集計単位、表示範囲、数値の区分その他の表示方法を調整することがあります。
7. 利用者が退会した場合、その利用者のプレイデータは統計および分析対象からも除外されます。
8. 公開設定の変更や退会より前に第三者が保存した情報、検索エンジンのキャッシュその他運営者が管理できない情報については、運営者が削除できない場合があります。

## 6. 外部サービスと外部への送信

:::note[かんたんに言うと]
ログイン、アクセス解析、不正利用対策、コンテンツ配信などにGoogle、Firebase、Cloudflare等を利用します。これらのサービスには、IPアドレスや端末情報などが送信される場合があります。
:::

本サービスでは、次の外部サービスを利用します。各サービスへ送信された情報は、それぞれの提供者が定めるプライバシーポリシー等に従って取り扱われます。

- [Google・Firebase](https://policies.google.com/privacy)：Googleログイン、Firebase Authenticationによる本人認証、Firebase Analyticsによる利用状況の把握
- [Cloudflare](https://www.cloudflare.com/privacypolicy/)：Turnstileによるボット・不正利用の防止、通信の配信および保護
- 外部のジャケット画像配信元：楽曲のジャケット画像その他外部コンテンツの表示

外部サービスの利用に伴い、利用者のIPアドレス、アクセス日時、ブラウザ・端末情報、識別子、閲覧ページその他各サービスの提供に必要な情報が、当該サービスの提供者へ送信される場合があります。また、当該情報が日本国外で取り扱われる場合があります。

運営者は、法令に基づく場合、人の生命・身体・財産の保護に必要な場合その他法令上認められる場合を除き、利用者に関する情報を本サービスと無関係な第三者へ販売または提供しません。

## 7. 端末内に保存する情報

:::note[かんたんに言うと]
ログイン状態や表示設定、キャッシュなどをブラウザ内に保存します。ブラウザの設定やChuniSupportのキャッシュ削除機能から削除できますが、再ログインや再設定が必要になる場合があります。
:::

1. 本サービスは、ログイン状態、テーマ、楽曲情報、プレイ記録のキャッシュ、検索条件、表示設定その他本サービスの提供に必要な情報を、Cookie、ローカルストレージ、IndexedDBその他利用者の端末内の保存領域に保存することがあります。
2. 利用者は、ブラウザの設定または本サービスのキャッシュ削除機能から、これらの情報を削除できます。
3. これらの情報を削除または無効化すると、一部の設定が初期化され、再ログインが必要になり、または本サービスの一部が正常に動作しない場合があります。

## 8. 保存期間と削除

:::note[かんたんに言うと]
アカウントのデータは退会まで保存します。退会するとプレイデータは統計からも除外します。一時登録データは原則5分で削除しますが、ログやバックアップには必要な期間残る場合があります。
:::

1. 利用登録前に送信された一時プレイデータおよびIPアドレスは、登録処理のため原則として5分間保持し、利用後または期限切れ後に削除します。
2. アカウントおよびアカウントに紐づく情報は、利用者が退会するまで、または本サービスの提供に必要な間保存します。
3. 利用者が設定画面から退会すると、本サービスのアカウント、プレイデータ、目標、フレンド関係、APIトークンその他アカウントに紐づくデータを削除し、当該プレイデータを統計からも除外します。また、本サービスで使用するFirebase Authenticationの認証記録を削除しますが、利用者のGoogleアカウント自体は削除しません。
4. 通信ログ、セキュリティ記録および問い合わせ対応履歴は、不正利用対策、障害対応、紛争対応および法令上の義務の履行に合理的に必要な期間保存します。
5. バックアップには、退会または削除後も、バックアップの更新または廃棄が完了するまで情報が残る場合があります。バックアップ内の情報は、障害復旧その他バックアップの目的以外には利用しません。
6. Firebase Analyticsその他外部サービスが保持する情報の保存期間は、運営者による設定および各サービス提供者の方針に従います。
7. 利用者の端末内に保存された情報は、退会後も残る場合があります。必要に応じて、ブラウザから削除してください。

## 9. 安全管理措置

:::note[かんたんに言うと]
必要な人だけがデータへアクセスできるようにし、通信の保護、APIトークンのハッシュ化、ログ監視などを行います。ただし、具体的な防御方法は安全上すべて公開しません。
:::

運営者は、取り扱う情報の漏えい、滅失、毀損および不正利用を防止するため、サービスの規模と情報の性質に応じ、主に次の措置を講じます。

1. 利用者に関する情報を取り扱う範囲と管理責任の明確化
2. データおよび管理機能へのアクセス制御
3. 通信経路の暗号化その他送受信時の保護
4. APIトークンのハッシュ化および認証情報の適切な管理
5. 不正アクセス、異常なアクセスおよびエラーの監視
6. 使用するソフトウェア、外部サービスおよび権限設定の定期的な確認と更新
7. 問題が発生した場合の調査、影響の限定、再発防止および法令に基づく報告・通知

安全管理に支障を及ぼすおそれがある具体的な設定、構成および防御方法は公開しません。

## 10. 情報の確認、訂正、削除等

:::note[かんたんに言うと]
プロフィール設定や退会は設定画面から行えます。それ以外の情報の確認、訂正、削除などは、問い合わせフォームから申し出られるようにします。
:::

1. 利用者は、本サービスの設定画面から、公開設定その他のアカウント情報を確認または変更できます。
2. 利用者は、設定画面から退会し、アカウントに紐づくデータの削除を行うことができます。
3. 設定画面で対応できない情報の確認、訂正、削除、利用停止その他の申出は、問い合わせフォームから受け付けます。
4. 運営者は、申出を行った者が利用者本人または正当な代理人であることを確認するため、必要な範囲で情報の提供またはログインによる確認を求めることがあります。本人確認のために、必要以上の情報を求めません。
5. 法令により申出に応じないことが認められる場合、または対象となる情報を保有していない場合は、その旨を申出を行った者へお知らせします。

## 11. 本ポリシーの変更

:::note[かんたんに言うと]
サービスや法律の変更に合わせて、このポリシーを変更する場合があります。重要な変更は、開始前にお知らせします。
:::

1. 運営者は、本サービスの内容、取り扱う情報、利用する外部サービスまたは法令等の変更に応じて、本ポリシーを変更することがあります。
2. 変更後の本ポリシーは、本ページに掲載した効力発生日から適用します。
3. 利用者の権利利益に重大な影響を及ぼす変更については、合理的な予告期間を設け、本サービスまたは本サービスのドキュメントでお知らせします。法令上同意が必要な場合は、変更後の取扱いを開始する前に同意を取得します。

## 12. 問い合わせ窓口

:::note[かんたんに言うと]
個人情報の取扱いについての質問や、情報の確認・訂正・削除等の申出は、専用の問い合わせフォームから受け付けます。
:::

本ポリシー、利用者に関する情報の取扱い、または情報の確認・訂正・削除等に関する問い合わせは、次の窓口で受け付けます。

- 問い合わせフォーム：**準備中（公開前にURLを掲載します）**

公開チャンネル、SNSその他第三者が閲覧できる場所には、本名、メールアドレス、APIトークンその他公開を希望しない情報を書き込まないでください。
