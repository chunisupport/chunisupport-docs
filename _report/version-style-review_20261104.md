## 対象バージョン

Astro 6.4.8、Starlight 0.40.0、TypeScript 6.0.3。`.node-version` と `engines.node` は22.12.0を基準としている。調査コマンドを実行した Node.js は24.19.0。

## 条件付きの更新候補

`package.json:13` のテストコマンドに `--experimental-strip-types` が残っている。

Node 22.18 / 23.6 以降は型除去が既定で有効で、Node 24系に実行基準を統一するなら明示指定は不要。

ただし本リポジトリの `.node-version` は22.12.0であり、そのバージョンを対応対象とするならフラグは必要。現状の実行基準に対して誤った記法ではなく、Node の実行基準を更新するときに合わせて見直す候補。一律に削除しない。

## 更新済みであることを確認した箇所

- コレクション設定は `src/content.config.ts` を使用。
- コレクション取得に loader を使用し、独自コレクションには `astro/loaders` の `glob` を使用。
- Zod は `astro/zod` から import。
- 記事の描画には `astro:content` の `render()` を使用。
- 旧 `Astro.glob`、`getEntryBySlug`、`ViewTransitions` の使用は検出していない。

## 確認結果と限界

- `astro check` は成功。19ファイル、エラー・警告・ヒントはいずれも0。
- Astro の代表的な旧 API の移行漏れは今回の範囲では見つからなかった。
- 全ビルド、Node 22.12.0 での再検証、ブラウザーの実機動作、依存パッケージ全件の外部リリースノート照合は実施していない。
